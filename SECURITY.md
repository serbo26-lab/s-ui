# Security policy

Please do not post vulnerability details or exploits in public issues or pull requests.

For vulnerabilities specific to **this fork**, use private vulnerability reporting in this repository's GitHub **Security** tab if it is available. Otherwise, request a secure contact channel from the repository maintainer without disclosing the issue publicly.

For vulnerabilities affecting unmodified upstream code, consult [alireza0/s-ui's security policy](https://github.com/alireza0/s-ui/security/policy).

The upstream maintainer's email and response-time commitments do not apply to this independent fork. Supported versions will be identified in this fork's releases.

The panel, API, installer and linked frontend are within scope. Third-party dependencies such as sing-box have their own maintainers.
